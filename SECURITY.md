# Security policy

## Reporting a vulnerability

Please do not disclose credential exposure, command execution or update-chain
vulnerabilities in a public issue.

Use GitHub's private vulnerability reporting feature for
`MAD-Producer/MAD-Toolbox`. Include the affected version, platform,
distribution mode, reproduction steps and a minimal redacted log. Do not
attach real cookies, passwords, tokens, BBDown sessions or private media.

We will acknowledge a report as soon as practical, investigate it privately
and coordinate disclosure after a fix is available.

## Diagnostic archives

MAD Toolbox diagnostic exports are designed to redact credentials, URLs and
user paths, and they do not read encrypted templates or operating-system
credential storage. Always inspect an archive before sharing it and send it
only to a developer you trust.

Only the latest tagged release is expected to receive security fixes.
